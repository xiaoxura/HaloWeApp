博主2026-02-20 · 阅读 128

为什么选择原生小程序

目标是单一微信平台，原生方案少一层框架抽象，官方文档直接可用，长期维护成本更低。网络层用 wx.request 自行封装即可。

JavaScript复制
// 封装 wx.request 请求文章列表
const res = await wx.request({
  url: '/apis/api.content.halo.run/v1alpha1/posts',
  data: { page: 1, size: 5 }
})
console.log(res.data.items)
